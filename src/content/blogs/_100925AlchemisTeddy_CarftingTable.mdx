This stylized low-poly prefab represents an alchemist’s crafting table, designed as part of a larger playable project.
The asset balances functionality and aesthetics: flat colors clearly highlight interactive elements for gameplay, 
while hand-painted details and a custom cauldron shader add artistic depth and atmosphere.

Built through close collaboration between art and programming, this piece reflects our ability to merge technical constraints with creative direction. 
It demonstrates a pipeline suitable for real-time applications, optimized performance, and modular scene integration.

This is version 1 of a work-in-progress project – further environments and gameplay assets are currently in development.
